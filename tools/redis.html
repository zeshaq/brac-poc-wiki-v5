Data & streaming

Redis (RedisFailover)

DCDR

3 Redis + 3 Sentinel pods per cluster — the platform's KV store, fed by the Kafka WAL.

Quick facts

Topology
3 Redis + 3 Sentinel
Failover
Sentinel-driven primary election in-cluster
Cross-cluster
Independent — fed asynchronously by redis-applier on each side

What it is

DC and DR Redis are not directly replicated. Each side has its own primary, sentinels, and replicas. Application writes that need cross-cluster durability go through Kafka and are replayed by redis-applier into the local Redis primary — eventually consistent, no Redis-level cross-site coupling.
