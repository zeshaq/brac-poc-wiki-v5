DCDR

Artifact and container registry for the lab — Maven repos live, Docker hosted now serving on port 5000, Docker proxy and group still to come.

What it is

Nexus runs per cluster on Longhorn-backed PVCs. The Docker hosted repo holds internal images (redis-applier already pushed manually; future Open Liberty / NGINX images for the brac-poc-openliberty CI flow land here). A future Docker proxy repo will absorb the slow/unreliable Quay.io and Docker Hub pulls that have hurt DR rollouts.

Architecture

Nexus runs per cluster as a single-replica StatefulSet on Longhorn-backed PVCs (data + blob store). Two ingresses per cluster: nexus.apps.sub.comptech-lab.com (UI + REST API on container port 8081) and nexus-docker.apps.sub.comptech-lab.com (Docker registry HTTP connector on container port 5000). The Service exposes both ports; the Docker ingress backends to nexus:5000 and the UI ingress to nexus:8081.

Edge HAProxy default-backend SNI passthrough routes both hostnames to the local cluster's nginx-ingress (DC by current wildcard match; no DC-primary/DR-backup wired yet — pending Plan-09 explicit nexus-be). DR Nexus is up and equally provisioned but not externally reachable until that backend lands.

Configuration

Source: clusters/<cluster>/manifests/nexus/ — Namespace, StatefulSet, Service, Ingress (regular + Docker), Certificate, PVC, plus the legacy nexus-provisioning ConfigMap of Groovy scripts (functionally inert: Nexus 3.74 does not auto-execute scripts mounted at /opt/sonatype/nexus/etc/scripts).

Repos created via REST API (POST /service/rest/v1/repositories/<format>/<type>) on each cluster:

  • docker-hosted — HTTP connector :5000, v1Enabled: false, forceBasicAuth: true, writePolicy: ALLOW_ONCE. Listens on container port 5000 inside the pod; reachable through the nexus-docker.apps... ingress at /v2/.
  • Maven set: maven-releases, maven-snapshots, maven-central (proxy), maven-public (group).
  • NuGet set: nuget-hosted, nuget.org-proxy, nuget-group.

Still to provision: docker-proxy (Docker Hub mirror), docker-group aggregating hosted + proxy, optional npm-proxy/helm-hosted.

Auth: machine accounts (mavenbot, jenkinsbot) need to be created in Nexus before Jenkins integration — the on-disk ~/cloud-init/nexus-{mavenbot,jenkinsbot,admin}-password files are stale from a prior install and do not match the live state. The bootstrap admin UUID at /nexus-data/admin.password on the pod is still the active admin credential (wizard never run); rotation is a separate follow-up. OIDC via Keycloak's nexus client is wired in the realm but not yet activated in Nexus.

Operations

  • UI: https://nexus.apps.sub.comptech-lab.com
  • Docker registry health: curl -skI https://nexus-docker.apps.sub.comptech-lab.com/v2/ — healthy state is HTTP/2 401 with WWW-Authenticate: BASIC and Docker-Distribution-Api-Version: registry/2.0. HTTP 502 means the connector is down or the docker repo was deleted.
  • Docker login: docker login nexus-docker.apps.sub.comptech-lab.com
  • Push image: docker tag <src> nexus-docker.apps.sub.comptech-lab.com/<name>:<tag> && docker push nexus-docker.apps.sub.comptech-lab.com/<name>:<tag>
  • List repos via REST: curl -sk -u admin:<pw> https://nexus.apps.sub.comptech-lab.com/service/rest/v1/repositories
  • Re-create the docker-hosted repo (if ever lost): POST /service/rest/v1/repositories/docker/hosted with body {name, online, storage{blobStoreName, strictContentTypeValidation, writePolicy}, docker{v1Enabled:false, forceBasicAuth:true, httpPort:5000}}. Restart not required — the connector binds immediately.
  • Backups: planned MinIO bucket nexus-blobs (CronJob not yet created — STATE.md TODO).

Failover

Independent per cluster. Each cluster has its own Nexus with its own data; pushed images on DC are NOT automatically on DR. Building once and pushing to both clusters' Nexuses is the current pattern (or use ctr import to bypass the registry entirely, as we did for Terrakube + AWX images on DR).

No DC-primary/DR-backup edge backend wired yet — both DC and DR Nexus instances now have docker-hosted on connector :5000, but nexus-docker.apps... only reaches DC via the edge HAProxy default SNI fall-through. Plan-09 will add an explicit nexus-rke2-be with DC primary + DR backup, mirroring the pattern used for Vault, Keycloak, Terrakube, AWX.
