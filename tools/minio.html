MinIO

Shared infra

S3-compatible object storage — backs Terrakube remote state and (planned) snapshot buckets.

Quick facts

Form
VM on br30
Buckets (live)
terrakube-state
Buckets (planned)
vault-snapshots, jenkins-rke2-backups, nexus-blobs

What it is

Used as a stable S3 endpoint outside both clusters so it's available regardless of which side of DC/DR is current. Application object data on the platform itself uses Longhorn PVCs.
