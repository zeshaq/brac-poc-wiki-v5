Data & streaming

Apache Kafka (KRaft)

DCDR

3 brokers + 3 controllers in KRaft mode per cluster — backbone of the cross-cluster replication path.

Quick facts

Mode
KRaft (no ZooKeeper)
Topology
3 brokers + 3 controllers
Internal listener
scram on 9095 (TLS + SCRAM-SHA-512)
External listener
Bootstrap + per-broker on 443 via SNI
AuthN/Z
SCRAM-SHA-512 + Strimzi simple authz; ANONYMOUS superuser on DR for MM2
Carrier topic
redis-writes (Redis WAL pattern, ADR-0018)

What it is

The two clusters are independent Kafka deployments. Cross-cluster delivery is via MirrorMaker 2 running on DR. External off-cluster clients reach Kafka via the edge HAProxy by SNI to bootstrap.kafka.apps.sub.comptech-lab.com:443 and broker-{0,1,2}.kafka.apps.sub.comptech-lab.com:443.
